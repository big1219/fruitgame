# 발보린 사업자몰 (VALVOLINE BIZ MALL)

정비소 · 카센터 · 세차장 등 사업자 대상 발보린(Valvoline) 전용 B2B 쇼핑몰 프로토타입.
불스원몰 스타일의 사업자 전용몰 구조를 참고해 제작했습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
```

## 구성

- `ValvolineMall.jsx` — 몰 전체 (단일 컴포넌트)
- `public/products/` — 실제 제품 사진 49종 (WebP, 800px)
- `FruitSlash.jsx` — 기존 게임 (몰과 무관, 보존용)

## 주요 기능

- **사업자 전용가 잠금** — 로그인 전에는 소비자가만 노출, 데모 로그인 시 공급가/할인율 공개
- **카테고리 7종** — 승용/상용 엔진오일, 미션·기어오일, 부동액, 이륜차, 농기계·산업유, 케미컬
- **상품 49종 전체 실사진** — 판매물량 데이터 기준 실제 취급 품목
- 검색, 베스트/특가 필터, 장바구니(수량 조절 · 무료배송 게이지), 대량구매 견적 배너
