# 🛢️ 발보린 엔진오일 찾기

차량번호를 입력하면 해당 차량에 맞는 엔진오일(점도·규격·주입량·교환주기)과
**발보린(Valvoline) 추천 제품**을 알려주는 웹 앱입니다.

> 발보린 공식 서비스가 아닌 비공식 참고용 앱입니다. 제품 라인업은 시장/시기에
> 따라 다를 수 있으므로 구매 전 제품 라벨의 점도·인증 규격을 확인하세요.

## 실행 방법

빌드가 필요 없는 단일 HTML 파일입니다.

```bash
# 브라우저에서 바로 열기
open oil-finder/index.html

# 또는 로컬 서버로
npx serve oil-finder
```

## 동작 방식

1. **차량번호 조회** — 번호판 형식(`12가3456`, `123가4567`, `서울12가3456`)을 검증한 뒤 차량정보를 조회합니다.
2. **직접 선택 폴백** — 번호로 조회되지 않으면 제조사 → 모델 → 엔진을 직접 선택할 수 있습니다.
3. **오일 추천** — 권장 점도, 규격(API/ILSAC/ACEA), 주입량, 교환주기, 주의사항을 보여줍니다.
4. **발보린 제품 매칭** — `recommendValvoline()`이 연료 타입(가솔린/디젤/하이브리드/LPG)과
   점도·규격에 맞는 제품을 "베스트 매치 / 대체 추천"으로 보여줍니다.

## ⚠️ 데모 버전 안내

**차량번호 → 차종 조회는 현재 데모 DB(샘플 6대)로 동작합니다.**

대한민국에서 차량번호만으로 차종을 조회하려면 외부 API 연동이 필요합니다:

| 서비스 | 제공처 | 비고 |
|---|---|---|
| 자동차365 자동차 기본정보 | 국토교통부 | 공공 서비스, 제휴 필요 |
| 카히스토리 차량정보 API | 보험개발원 | 유료, 사업자 계약 |
| NICE자동차정보 / 카머스 등 | 민간 | 유료 API |

연동 방법: `index.html`의 `lookupVehicleByPlate()` 함수 내부의 데모 DB 조회를
실제 API `fetch` 호출로 교체하면 됩니다. 나머지 UI/오일 DB는 그대로 사용 가능합니다.
